--------------------------------------------------------

第 1 步：把图片放回原位置
  把 founder.webp、class.webp 这两个文件
  复制到：C:\Users\mudream\english-camp\src\assets\modal\
  （该文件夹里本来就有这两个文件，我没有删；如果以后被删了，就用这里的补回去）

第 2 步：改一个文件，取消注释
  用记事本打开：C:\Users\mudream\english-camp\src\components\AboutDetail.jsx
  找到这两段被 /* */ 包起来的地方，把 /* 和 */ 删掉即可：

  ── 靠文件顶部 ──
     import founder from '../assets/modal/founder.webp'
     import classPic from '../assets/modal/class.webp'

  ── 中间 photos 数组里 ──
     { src: founder, alt: '余国良博士照片', credit: true },
     { src: classPic, alt: 'TIFSC 公益口语课堂合影' },

  注意：
  ▸ /* 和 */ 必须成对删掉，只删一个会白屏（语法错误）
  ▸ 只动注释符号，别改引号里的文字
  ▸ 改完在项目里跑一次 npm run build，双击打开的 dist/index.html 才会更新
